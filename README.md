# Milton's Garden

Website for Milton's Garden, a private family farm house in Vottopur, Sonargaon (Narayanganj, Bangladesh).

Live site: https://tiger-park-limited.github.io/milton-garden/

## Structure

- `index.html` — the whole site (HTML + CSS in one file)
- `assets/img/` — photos and logo
- `assets/video/pond.mp4` — short looping clip of the pond used in the header

## Updating

Edit `index.html` or replace files in `assets/`, commit and push to `main`. GitHub Pages republishes automatically within a minute or two.

To add a photo to the gallery, put it in `assets/img/` (ideally under 1600 px wide) and add a `<figure>` in the Gallery section.
